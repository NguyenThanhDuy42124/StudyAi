Master Blueprint
Tài liệu kiến trúc đầy đủ — AI Student Assistant Platform
Stack: FastAPI + React + Gemini API + Qdrant + PostgreSQL + Docker → Ubuntu 24.04 LTS

✅ Decisions đã chốt — Không thay đổi

AI: Gemini 2.0 Flash (chính) → NVIDIA Build (fallback 1) → Groq (fallback 2). Không Dify.
RAG: Tự build với Qdrant client trực tiếp (không LlamaIndex). Gemini text-embedding-004 cho embedding.
Intent Routing: Hybrid — keyword-first → LLM fallback → default Study RAG.
MCQ: Tối đa 50 câu (10/20/30/50). Lưu DB 7 ngày. A/B/C/D + đáp án + giải thích.
UI Libraries: ReUI (components) + Lucide (icons) + UIverse (effects/animations).
Admin Portal: Có. Quản lý sổ tay SV + users + analytics.
RAG Collections: 2 loại — docs_user_{id} (personal) + handbook_shared (sổ tay SV).
VPS: 4 CPU / 8GB RAM / 80GB SSD / Ubuntu 24.04 LTS. Đủ dư.
Upload limit: 200MB/user. File types: PDF, DOCX, TXT, PPTX.

       Response: list[DocumentPublic]
       → Chỉ trả documents của current user

# rag/chunker.py
# ⚠️ QUAN TRỌNG: chunk_size=500 là số TỪ (words), KHÔNG phải tokens.
# ~500 từ ≈ 650-700 tokens (tiếng Việt). Đây là lựa chọn chủ ý để đơn giản.
# Nếu muốn đếm token chính xác: pip install tiktoken, dùng cl100k_base encoding.
def chunk_text(text: str, chunk_size=500, overlap=50) -> list[dict]:
    """Cắt text thành chunks, trả về list[{text, start_char, index}]
    
    Args:
        chunk_size: Số TỪ mỗi chunk (500 words ≈ 650 tokens tiếng Việt)
        overlap: Số từ overlap giữa 2 chunks liên tiếp (giảm mất context)
    """
    words = text.split()
    chunks = []
    i = 0
    while i < len(words):
        chunk_words = words[i:i+chunk_size]
        chunks.append({"text": " ".join(chunk_words), "index": len(chunks)})
        i += chunk_size - overlap
    return chunks

    """Tìm top_k chunks gần nhất với câu hỏi"""

#       full_text += delta

async def answer_with_rag(query: str, user_id: UUID) -> tuple[AsyncIterator[str], list[dict]]:
    """Full RAG: retrieve → build prompt → stream Gemini.
    
    Returns:
        (stream_generator, sources_list) — sources cần lưu vào DB sau khi stream xong.
    """
    chunks = await retrieve(query, user_id, top_k=5)
    sources = [{"document_id": c["document_id"], "text": c["text"][:200]} for c in chunks]
    context = "\n\n---\n\n".join(c["text"] for c in chunks)

    system = "Bạn là trợ lý học tập. Trả lời dựa trên tài liệu được cung cấp. Nếu không tìm thấy thông tin, hãy nói rõ."
    prompt = f"Tài liệu tham khảo:\n{context}\n\nCâu hỏi: {query}"

    async def _stream():
        async for chunk in ai_gateway.stream([
            ChatMessage("system", system),
            ChatMessage("user", prompt)
        ], model="gemini-2.0-flash"):
            yield chunk.delta

    return _stream(), sources

    @abstractmethod

    @abstractmethod

class RateLimitError(Exception): should_fallback = True   # 429, quota exceeded
class TimeoutError(Exception):   should_fallback = True   # request timeout
class ServerError(Exception):    should_fallback = True   # 5xx
class InvalidRequestError(Exception): should_fallback = False  # 400, bad prompt
class ContentPolicyError(Exception):  should_fallback = False  # content filtered

# ai/router/model_router.py
class ModelRouter:
    def __init__(self):
        self.providers = {
            "gemini": GeminiProvider(api_key=settings.GEMINI_API_KEY),
            "nvidia": NvidiaProvider(api_key=settings.NVIDIA_API_KEY),
            "groq":   GroqProvider(api_key=settings.GROQ_API_KEY),
        }
        self.chain = ["gemini", "nvidia", "groq"]  # fallback order

    async def chat(self, messages, **kwargs) -> ChatResponse:
        for provider_name in self.chain:
            provider = self.providers[provider_name]
            try:
                return await provider.chat(messages, **kwargs)
            except Exception as e:
                if not getattr(e, "should_fallback", True):
                    raise  # Lỗi không fallback (bad request, content policy)
                # Log và thử provider tiếp theo
                logger.warning(f"{provider_name} failed: {e}, trying next...")
        raise Exception("All providers failed")

📄 Document Processing — PDF/DOCX → Markdown (tối ưu token)

Tại sao chuyển sang Markdown? Raw text extraction từ PDF bỏ mất cấu trúc (headings, tables, lists). LLM đọc Markdown hiệu quả hơn nhiều vì cấu trúc rõ ràng, ít garbage whitespace, giữ context giữa các section. Token-wise: Markdown thường nhỏ hơn raw text ~20-30%.

Thư viện đề xuất: markitdown (Microsoft, 2024)

markitdown — pip install markitdown
  • PDF → Markdown (giữ headings, tables, lists)
  • DOCX → Markdown (styles, tables)
  • PPTX → Markdown (slide titles, bullet points)
  • TXT → pass-through
  • Maintained by Microsoft, cập nhật thường xuyên
Backup: pymupdf4llm — pip install pymupdf4llm
  • Tập trung vào PDF, xử lý layout tốt hơn markitdown
  • Phân tích column layout (multi-column PDF)
  • Dùng khi markitdown fail với PDF phức tạp
  • Kết hợp: markitdown trước, fallback pymupdf4llm

Parser implementation

# rag/parsers/__init__.py
from markitdown import MarkItDown
import pymupdf4llm

md_converter = MarkItDown()   # singleton

def parse_to_markdown(file_path: str, file_type: str) -> str:
    """
    Chuyển tài liệu sang Markdown để tối ưu token khi đưa vào LLM.
    Priority: markitdown → fallback pymupdf4llm (chỉ PDF) → raw text.
    """
    try:
        result = md_converter.convert(file_path)
        text = result.text_content
        if len(text.strip()) > 100:          # markitdown thành công
            return _clean_markdown(text)
    except Exception as e:
        logger.warning(f"markitdown failed for {file_path}: {e}")

    # Fallback 1: pymupdf4llm (chỉ PDF)
    if file_type == "pdf":
        try:
            return pymupdf4llm.to_markdown(file_path)
        except Exception:
            pass

    # Fallback 2: raw text (không nên xảy ra)
    return _raw_extract(file_path, file_type)


def _clean_markdown(text: str) -> str:
    """Dọn garbage: multiple blank lines, page numbers, headers/footers lặp."""
    import re
    text = re.sub(r'\n{3,}', '\n\n', text)          # max 2 blank lines
    text = re.sub(r'^\s*\d+\s*$', '', text, flags=re.MULTILINE)  # page numbers
    text = text.strip()
    return text

Vấn đề: Gemini 2.0 Flash có context window 1M tokens nhưng free tier có giới hạn. Quan trọng hơn là chi phí token — càng nhiều lịch sử chat thì prompt càng dài, response chậm hơn và tốn quota hơn.
# rag/pipeline.py — Build prompt thông minh

CHAT_HISTORY_LIMIT = 10     # Chỉ giữ 10 messages gần nhất trong context
RAG_CHUNKS_LIMIT = 5        # Top-5 chunks từ Qdrant
MAX_CHUNK_TOKENS = 500      # Mỗi chunk tối đa 500 tokens
MAX_CONTEXT_TOKENS = 3000   # Budget cho RAG context

async def build_chat_prompt(
    query: str,
    conversation_id: UUID,
    user_id: UUID,
    intent: Intent,
    db: Session
) -> list[ChatMessage]:
    """
    Xây dựng prompt với sliding window history + RAG context.
    Tổng: system (200) + history (1000) + rag_context (3000) + query (300) ~ 4500 tokens
    """
    messages = []

    # 1. System prompt (ngắn gọn)
    system = build_system_prompt(intent)
    messages.append(ChatMessage("system", system))

    # 2. RAG context — lấy chunks liên quan
    chunks = await retrieve_chunks(query, user_id, intent, top_k=RAG_CHUNKS_LIMIT)
    if chunks:
        context_text = "\n\n---\n\n".join(
            f"[Nguồn {i+1}]: {c['text'][:MAX_CHUNK_TOKENS*4]}"  # 4 chars ~ 1 token
            for i, c in enumerate(chunks)
        )
        messages.append(ChatMessage("system",
            f"Tài liệu tham khảo (dùng để trả lời, đừng bịa thêm):\n{context_text}"
        ))

    # 3. Chat history — chỉ N messages gần nhất (sliding window)
    history = get_recent_messages(conversation_id, limit=CHAT_HISTORY_LIMIT, db=db)
    messages.extend([ChatMessage(m.role, m.content) for m in history])

    # 4. Câu hỏi hiện tại
    messages.append(ChatMessage("user", query))

    return messages


def build_system_prompt(intent: Intent) -> str:
    base = "Bạn là trợ lý học tập AI cho sinh viên đại học. Trả lời bằng tiếng Việt, ngắn gọn và chính xác."
    if intent == Intent.STUDY:
        return base + " Chỉ trả lời dựa trên tài liệu được cung cấp. Nếu không tìm thấy thông tin, nói rõ."
    elif intent == Intent.HANDBOOK:
        return base + " Dựa vào sổ tay sinh viên. Luôn trích dẫn trang/mục cụ thể."
    return base

🗄️ RAG & Database — Vấn đề đồng bộ (Source of Truth)

Vấn đề user đề cập: "Phải lưu phần RAG lên database vì nó sẽ phát sinh thêm". Rất chính xác! Nếu chỉ ném text vào Qdrant, ta sẽ mất kiểm soát (khó xóa, khó update, không biết chunk nào thuộc file nào nếu Qdrant lỗi). Cần PostgreSQL làm "Source of Truth".

Giải pháp: Bảng DocumentChunks trong PostgreSQL

Schema Bổ sung (PostgreSQL)
class DocumentChunk(SQLModel, table=True):
    id: UUID = Field(default_factory=uuid4, primary_key=True)
    document_id: UUID = Field(foreign_key="document.id")
    chunk_index: int       # Thứ tự chunk
    text_content: str      # Nội dung text thực sự
    qdrant_point_id: str   # ID tương ứng trong Qdrant
    tokens_count: int      # Tối ưu billing
    created_at: datetime
    
    # Quan hệ
    document: Document = Relationship(back_populates="chunks")
Lợi ích tuyệt đối của việc lưu vào DB
  • Cascade Delete: Khi xóa Document, ta query được toàn bộ qdrant_point_id để xóa bên Qdrant an toàn.
  • Disaster Recovery: Nếu Qdrant crash mất data, ta có thể re-embed lại toàn bộ từ PostgreSQL mà không cần user upload lại file.
  • Audit & Debug: Khi AI trả lời sai, admin/dev có thể check chính xác text trong DB thay vì phải query Qdrant.

Luồng Indexing an toàn (2-Phase Commit concept)

# rag/indexing.py
async def index_document(document_id: UUID, db: Session):
    # 1. Parse PDF -> Markdown
    text = parse_to_markdown(file)
    
    # 2. Chunking
    chunks = text_splitter.split_text(text)
    
    # 3. Embed & Lưu đồng thời
    for i, chunk_text in enumerate(chunks):
        # Tạo vector
        vector = await embed_text(chunk_text)
        point_id = str(uuid4())
        
        # A. Lưu vào DB trước (Transaction)
        db_chunk = DocumentChunk(
            document_id=document_id,
            chunk_index=i,
            text_content=chunk_text,
            qdrant_point_id=point_id
        )
        db.add(db_chunk)
        
        # B. Upsert vào Qdrant
        qdrant.upsert(
            collection_name=collection,
            points=[PointStruct(id=point_id, vector=vector, payload={"doc_id": str(document_id)})]
        )
    
    db.commit() # Hoàn thành cả 2

1. Rate Limiting (Chống Spam / Abuse)

Free API (Gemini/Groq) rất dễ bị cạn kiệt nếu 1 user spam click "Tạo Quiz". Cần implement Rate Limit ở tầng FastAPI.

2. Status Updates (Trạng thái Async Tasks)

Khi user upload file 50 trang, việc parse và embed mất khoảng 20-30s. Frontend không thể chờ HTTP request 30s (sẽ bị timeout). Giải pháp?
Phương án 1: Short Polling (Đề xuất vì dễ làm)
  • API POST /upload trả về ngay {"status": "indexing", "doc_id": "123"}
  • Frontend dùng setInterval hoặc TanStack Query refetchInterval: 3000 gọi API GET /docs/123 mỗi 3 giây.
  • Khi status chuyển sang "ready" hoặc "failed" thì dừng poll và hiện thông báo.
Phương án 2: WebSockets / SSE
  • Server push trực tiếp event "doc_ready" xuống client.
  • Ưu điểm: Real-time, mượt.
  • Nhược điểm: Setup phức tạp hơn, tốn connection của server. Với tính chất hệ thống này, Polling là đủ tốt.

/**
 * src/components/common/AsyncButton.tsx
 * Nút bấm tự động hiện trạng thái Loading khi hàm onClick là Async.
 * Giúp code gọn, không cần tự quản lý state `isLoading` ở mọi nơi.
 */
import { useState } from "react";
import { Button, ButtonProps } from "@/components/ui/button";
import { Loader2 } from "lucide-react";

interface AsyncButtonProps extends ButtonProps {
  onClick: () => Promise<void>; // Ép kiểu bắt buộc trả về Promise
}

export function AsyncButton({ onClick, children, ...props }: AsyncButtonProps) {
  const [loading, setLoading] = useState(false);

  const handleClick = async () => {
    try {
      setLoading(true);
      await onClick();
    } finally {
      setLoading(false);
    }
  };

  return (
    <Button onClick={handleClick} disabled={loading || props.disabled} {...props}>
      {loading && <Loader2 className="mr-2 h-4 w-4 animate-spin" />}
      {children}
    </Button>
  );
}
